# 利用規約（下書き）

> 本書は下書きである。公開前に内容を確認し、正式版として差し替えること。

## 1. サービスの内容

FORGE は、ユーザーが Blueprint（コマンドと自動化の定義）を作成し、
Discord サーバー内で実行できる Bot である。

## 2. 禁止事項

- Blueprint を使ったスパム、嫌がらせ、他者の権利を侵害する行為
- Discord の利用規約および開発者ポリシーに反する行為
- FORGE のレート制限やクールダウンを回避しようとする行為

## 3. 運営による停止

禁止事項に該当する場合、または Bot 全体の安定運用に必要な場合、
運営は予告なく対象ギルドでの実行を停止、または全ギルドの実行を
停止（全局停止スイッチ）することがある。

## 4. データの取り扱い

保存するデータの種類と、書き出し・削除の方法はプライバシーポリシーに
定める。Blueprint の定義・変数・カウンターはギルドの管理者が
書き出しと全削除を行える。

## 5. 免責

FORGE は現状のまま提供される。ユーザーが作成した Blueprint の実行結果
について、運営は責任を負わない。
