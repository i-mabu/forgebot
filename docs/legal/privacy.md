# プライバシーポリシー

制定日: 2026-11-18

## 1. 保存するデータ

FORGE は、機能の提供に必要な範囲で次のデータを保存する。

- ギルド ID（サーバーの識別子）
- Blueprint の定義（コマンド名、条件、アクション、表示設定）
- Blueprint の実行に使う変数とカウンターの値
- 実行回数などの集計値
- サーバーの記憶（管理者が候補を登録し、承認した名言・記念日などの
  キー、種別、内容、承認状態、作成者と承認者のユーザー ID）
- 親密度の算出に使う成長データ（実行総数、稼働日数、最終稼働日）
- プラグインの有効化状態（ギルドごとのプラグイン名と有効・無効）

メッセージ本文は保存しない。FORGE は Privileged Intent を使用せず、
メッセージ本文へのアクセスを必要としない設計である。記憶として保存
されるのは、管理者が `/forge memory propose` で明示的に登録し、
承認された内容だけであり、メッセージが自動で保存されることはない。

## 2. データの利用目的

保存したデータは、導入されたギルド内での Blueprint の実行にのみ使う。
第三者への提供や、広告目的での利用はしない。

## 3. データの書き出しと削除

ギルドの管理者は、そのギルドのデータを書き出すこと、および全て削除
することができる。書き出しには Blueprint・変数・カウンターに加えて
記憶・成長データ・プラグイン有効化状態が含まれる。削除したデータは
復旧できない。

## 4. 保管期間

データはギルドに FORGE が導入されている間保管する。ギルドから FORGE が
削除された場合は、管理者の操作または運営への依頼により削除する。
