# プライバシーポリシー（下書き）

> 本書は下書きである。公開前に内容を確認し、正式版として差し替えること。

## 1. 保存するデータ

FORGE は、機能の提供に必要な範囲で次のデータを保存する。

- ギルド ID（サーバーの識別子）
- Blueprint の定義（コマンド名、条件、アクション、表示設定）
- Blueprint の実行に使う変数とカウンターの値
- 実行回数などの集計値

メッセージ本文は保存しない。FORGE は Privileged Intent を使用せず、
メッセージ本文へのアクセスを必要としない設計である。

## 2. データの利用目的

保存したデータは、導入されたギルド内での Blueprint の実行にのみ使う。
第三者への提供や、広告目的での利用はしない。

## 3. データの書き出しと削除

ギルドの管理者は、そのギルドのデータを書き出すこと、および全て削除
することができる。削除したデータは復旧できない。

## 4. 保管期間

データはギルドに FORGE が導入されている間保管する。ギルドから FORGE が
削除された場合は、管理者の操作または運営への依頼により削除する。
